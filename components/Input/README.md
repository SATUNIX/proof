Input is a labelled text field: 2px border, `surface` ground, 16px Archivo text. The consumer provides `label` (always), `hint` (one short line) or `error` (replaces the hint, shows the error glyph, and turns the border `danger`). `type`, `placeholder`, `value`/`defaultValue`, `onChange`, `disabled` pass through. Focus shows the 3px `focus` ring. Never use a placeholder in place of a label.
